# Cyberpunk Clock

A minimal digital clock with a neon-green, cyberpunk terminal-inspired design. It displays the current local time in 24-hour format and updates every second.

## Run

Open `index.html` in a web browser. No installation, dependencies, or build step are required.

## Project files

- `index.html` - Clock page structure and script/style references.
- `style.css` - Terminal-inspired appearance and responsive layout.
- `clock.js` - Reads the browser's local time and refreshes the display every second.
